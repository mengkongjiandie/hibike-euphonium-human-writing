# 原创性与用途边界

## 可以迁移的内容

- 用共同目标组织群体，再用稀缺资源、评价制度和责任分配制造摩擦。
- 让人物公开说法、真实愿望和实际行动保持可理解的错位。
- 用训练、失误、复盘和重复任务呈现能力变化。
- 让配角拥有独立目标，并记住前文造成的麻烦、帮助和误会。
- 让心理状态通过选择、后果、距离和声音显现。
- 让成长与输赢部分脱钩：努力不保证获胜，失败也不取消成长。

## 不得迁移的内容

- 原作人物、学校、社团、乐曲、称谓和其他专有设定。
- 原作具体比赛流程、选拔顺序、冲突组合、关系结局和场面调度。
- 原台词、对白来回、角色口吻、作者句法或译文表面。
- 把原创人物逐一对应为原作人物的换名版本。
- 以“像武田绫乃写的”或“京都动画风格”为交付目标。

## 六类安全重设计

若原创方案与原作过近，至少改变以下结构中的两项，直到新结果能由原创设定独立推出：

1. **制度**：改变组织如何分工、评价和惩罚。
2. **稀缺资源**：改变人物争夺的时间、资格、设备、钱或注意力。
3. **关系结构**：改变谁依赖谁、谁承担后果、谁掌握决定权。
4. **因果链**：改变冲突被触发、升级和缓和的原因。
5. **空间**：改变人物必须相遇、被看见或能够离开的场所规则。
6. **结果**：改变获益者、受损者和下一章继承的处境。

只更换姓名、学校、乐器或比赛名称不算重设计。

## 四问反向检查

1. 删除专有名词后，是否仍能指认原作中的某个具体场面？
2. 人物关系是否只能依靠原作角色组合才能成立？
3. 冲突是否直接复制原作制度、顺序和结果？
4. 文字是否在追求作者或某一译本可辨认的句法与口吻？

任一答案为“是”，停止生成近似文本，回到六类安全重设计。

## 去AI味的用途限制

去AI味只处理文本质量：机械动作、重复解释、主题结算、伪洞见、整齐节奏、过度闭合因果和同质化声音。不得承诺通过检测器，不得帮助隐瞒代写事实，也不得把“更像人写”解释成冒充特定作者。
